A GODOT project to experiment with how 3D perlin noise functions can create realistic, explorable environments. Renders onto an icosphere and categorises biomes based on moisture, latitude and temperature.
The primary project scene is scenes/world.tscn, feel free to have a roam around and let me know any further ideas, this one has been left behind a bit but I wouldn't mind picking it back up again!
